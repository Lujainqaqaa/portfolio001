# Lujain Qaqaa — Portfolio

A responsive personal portfolio made with HTML and CSS. Open `index.html` in a browser to view it. The images are stored beside the HTML file, so keep them in the same folder.

## Add your account links

Open `index.html` and find the footer section near the end of the file. Each social icon is an `<a>` link with an `aria-label`.

- WhatsApp: replace `https://wa.me/962XXXXXXXXX` with your international phone number after `wa.me/` (digits only, including country code).
- Facebook: replace `https://www.facebook.com/your-profile` with your profile URL.
- GitHub: replace `https://github.com/your-username` with your profile URL.
- Instagram: replace `https://www.instagram.com/your-username` with your profile URL.
- LinkedIn: the existing URL points to the profile included in the original portfolio; replace it if needed.
- Email: the existing `mailto:lujainqaqaa019@gmail.com` link opens an email draft. Change the address in both the footer icon and contact area if needed.

The two reference cards already contain the names, emails, and LinkedIn links from the original portfolio. Update their `<a href="...">` values in the `#references` section if you want different links.
